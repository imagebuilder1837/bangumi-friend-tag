# 好友标签数据按登录账号全局一份

标签面板同时出现在自己的好友/反向好友页和**他人的**好友/反向好友页。我们决定：标签数据不按页面所有者分桶，而是每个登录账号全局一份，以好友的用户标识索引；在他人的好友页给"他人的好友"打标签，也写入自己账号的同一份数据，筛选逻辑在所有页面完全一致。

这样选择的理由：`chiiApp.cloud_settings` 本身按登录账号隔离，按页面所有者分桶需要额外编码页面归属，而"我给某个用户打的标签"的语义不依赖于我是在谁的好友页上打的。

## Considered Options

- **按页面所有者分桶**：数据边界与页面视觉边界一致，但存储复杂、"同一个人"在不同桶中标签不一致，违背"标签描述的是这个用户"的直觉，故放弃。
